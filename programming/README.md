# Hello, World! in 57 Programming Languages

Each file in this folder contains a minimal, runnable "Hello, World!" program
(or the closest idiomatic equivalent) written in a different programming
language.

## Languages included

Python, JavaScript, TypeScript, Java, C, C++, C#, Go, Rust, Ruby, PHP,
Swift, Kotlin, Scala, Perl, Haskell, Lua, R, Dart, Elixir, Erlang, Clojure,
F#, Julia, OCaml, Bash, PowerShell, Visual Basic, Objective-C, Fortran,
COBOL, Pascal, x86 Assembly, SQL, MATLAB, Groovy, Scheme, Common Lisp,
Prolog, Crystal, Nim, Zig, Racket, Solidity, Ada, D, Elm, Vala, Tcl,
Smalltalk, VBScript, AppleScript, Forth, Brainfuck, HTML, CSS, Zsh

## Notes

- File extensions match the standard convention for each language, so most
  editors/IDEs will auto-detect syntax highlighting correctly.
- These are meant as quick reference samples, not production code — some
  (e.g. COBOL, Assembly, Brainfuck) require specific toolchains/compilers to
  run.
- Not every programming language ever created is included (there are
  thousands, including many obscure/esoteric ones) — this covers the most
  widely used and historically significant languages.
